# Ziph: art prompts (11-15), the same layered look as Keilah

Each room has three layers sliding at different speeds:
- **far:** the full picture, with sky.
- **mid:** the sky keyed out.
- **near:** a strip along the bottom, with everything above it keyed out.

The key color is **magenta (#FF00FF)** in the green woods of Horesh, and **green (#00FF00)** everywhere else. Every
prompt below is complete, so paste one per image.

Save them in `david-sling-2-art/ziph/` as `hills far.png`, `hills mid.png`, `hills near.png`, and so on, using the
room names below: hills, horesh, hachilah, maon, mountain. **The most needed come first.**

Until the art arrives, the first pass uses stand-ins from the two games, as Keilah did.
