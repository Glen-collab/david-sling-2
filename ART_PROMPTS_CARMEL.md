# Carmel: art prompts (11-20), the same layered look as En-Gedi and Ziph

Each outdoor room has three layers sliding at different speeds:
- **far:** the full picture, with sky.
- **mid:** the sky keyed out.
- **near:** a strip along the bottom, with everything above it keyed out.

The key color is **magenta (#FF00FF)** for the green fields and hills (green grass would get keyed out with green), and
**green (#00FF00)** everywhere else. Every prompt below is complete, so paste one per image.

Save them in `david-sling-2-art/carmel/` as `fields far.png`, `nabal mid.png`, `road near.png`, and so on, using the
room names below: fields, hills, night, nabal, store, road, valley, camp. **The most needed come first.**

Until the art arrives, the first pass uses stand-ins: the Spring and the Sheep Pens from En-Gedi, Keilah's town.
