# En-Gedi: art prompts (11-18), the same layered look as Ziph

Each outdoor room has three layers sliding at different speeds:
- **far:** the full picture, with sky.
- **mid:** the sky keyed out.
- **near:** a strip along the bottom, with everything above it keyed out.

The key color is **magenta (#FF00FF)** for the green Spring, and **green (#00FF00)** everywhere else. Every prompt
below is complete, so paste one per image.

Save them in `david-sling-2-art/engedi/` as `camp far.png`, `pens mid.png`, `spring near.png`, and so on, using the room
names below: camp, pens, spring, rocks, wild. **The most needed come first.**

Until the art arrives, the first pass (#9-11) uses stand-ins: Adullam's camp, Keilah's threshing floors and forest, and
Ziph's mountain and Maon.
